    灭菌锅（高压蒸汽灭菌）操作流程¶

    日期：2026-08-24 对象：枪头、PA 瓶（瓶子）、培养基等实验用品 核心原则：让饱和蒸汽充分接触每个物品表面；物品干燥后再保存。

    一、灭菌前准备¶

    1. 清洗：物品洗净，尽量晾干/甩干再装袋（减少袋内水分，避免炸包）。
    2. 包装（关键）：
    3. 枪头等小件：装入专用灭菌袋（标注 autoclave 121 ℃），袋口留缝或用纸塑袋（纸面透气）。不要用普通 PE/PP 袋，不要密封压空空气。
    4. 瓶子（PA 瓶、蓝盖瓶）：瓶盖松半圈（不要拧紧），或用铝箔松松盖住并留通气孔；瓶内液体不要装超过 2/3。
    5. 物品不要装太满，袋子之间留空隙。
    6. 标识：贴灭菌指示胶带（变色胶带），写明名称、日期、灭菌人。

    灭菌袋"留口"的具体操作¶

    记住：留口只是灭菌过程中的需要，让蒸汽进出；灭菌干燥完成后，可以再把袋口封严保存。

    情况一：纸塑灭菌袋（一面纸、一面塑料，自带封条/热封）¶

    • 物品放入后，留出约 1/3 长度的封口区，不要塞满。
    • 用封口机热封或按压自带胶条封口。
    • 放置时纸面朝上/朝外，蒸汽从纸面进入，干燥阶段水分也从纸面散出。
    • 注意：纸面不要被物品顶破；纸面湿透后强度下降，取出时轻拿。

    情况二：普通自封袋（拉链袋）——实验室最常见，留口方法任选其一¶

    1. 拉链留一段不压合：把拉链从一头压到一半，在角上留 1~2 cm 不封，形成一个通气小口。
    2. 压到底但折角留缝：拉链全部合上后，在袋口一角剪一个小缺口（1 cm 左右），或用镊子撑开一角。注意：剪口位置放上方，避免冷凝水从缺口流进。
    3. 灭菌胶带留缝法：袋口折两折（卷边），中间用一小段灭菌指示胶带粘住固定，胶带不要贴满，留出透气缝。
    4. 橡皮筋松扎：袋口卷起后用橡皮筋松松扎一圈（能透气），不打死结。
    5. 放置时袋口朝上或侧放，避免冷凝水倒灌。

    情况三：饭盒 / 不锈钢灭菌筒¶

    • 使用侧壁带通气孔的灭菌盒；盖子虚盖不扣死（错位盖或松搭扣），让蒸汽进出。
    • 蒸汽从通气孔进入；冷凝水留在盒底槽内，不接触物品。

    情况四：镊子、玻璃吸管等用牛皮纸卷包¶

    • 用牛皮纸/报纸把物品卷住，两端卷紧折口，留出缝隙透气，或用棉线/胶带松绑，不要封死。

    留口后的注意事项¶

    • 先晾干再装袋：袋内水分越少，炸包和湿袋风险越低。
    • 干燥阶段：灭菌结束后开启干燥程序，水分从留口/纸面散出；取出后若仍潮湿，放入 60~70 ℃ 烘干箱。
    • 保存：干燥后把拉链袋完全封严、标注日期；纸塑袋保持纸面完整即可，装入干净容器（如自封袋）再存放。

    二、装锅¶

    • 装入物品总量不超过锅容积的 2/3，顶部留出蒸汽空间。
    • 物品之间留缝隙，让蒸汽流通；瓶口斜放/倒放，利于蒸汽进入和冷凝水聚集。
    • 检查锅内水位、密封圈、排气阀正常。

    三、设置参数¶

    对象 温度 时间
    枪头、空瓶等干燥物品 121 ℃ 20~30 min
    培养基/液体（体积较大） 121 ℃（大体积可用 115 ℃/30 min） 15~20 min
    • 液体灭菌：灭菌结束必须选自然降温（慢排），防止爆沸冲出。
    • 若机器有 干燥程序，结束阶段开启，把物品烘干。

    四、运行与结束¶

    1. 启动后，等锅内温度达到 121 ℃ 时才开始计时。
    2. 灭菌结束：先自然降温，压力归零后再开门（液体务必等到压力完全归零，不要强行放气）。
    3. 开门时留一条缝，让余汽缓慢排出，待温度下降再取出。
    4. 检查灭菌效果：灭菌指示胶带已变色 = 常规合格；关键实验可加生物指示剂（芽孢条）验证。

    五、取出与保存¶

    • 取出时戴隔热手套，防止烫伤。
    • 干燥：若袋内还有水汽，放 60~70 ℃ 烘干箱干燥后再密封。
    • 保存：袋口密封好，标注灭菌日期；长期保存需保持干燥。

    常见错误检查表¶

    • [ ] 用普通塑料袋 → 换成专用灭菌袋
    • [ ] 袋子完全密封 → 必须留气口/用纸塑袋
    • [ ] 瓶盖拧紧 → 松半圈
    • [ ] 物品带水装袋 → 晾干再装
    • [ ] 装太满 → 不超锅容积 2/3
    • [ ] 结束强排汽 → 自然降温，压力归零再开门
    • [ ] 温度未到 121 ℃ 就计时 → 升温到设定值后开始计时
